Social Network Authentication & Posts API

Endpoint contracts, required scopes, and documented responses

Source of truth: Week6/openapi.yaml  ·  Base URL: https://api.example.com/v1  ·  Access JWT: 15 minutes  ·  Refresh token: opaque, single use
POST

/auth/login

Authenticate with email and password. Generic failure message prevents account enumeration.

Required scope
None · public
JSON request
{
  "email": "an@example.com",
  "password": "example-password"
}
Responses
200Access JWT + refresh token issued
400Malformed or missing request fields
401Invalid email or password
429Too many login attempts
POST

/auth/refresh

Exchange a single-use refresh token. A successful request invalidates the old token.

Required scope
None · refresh credential
JSON request
{
  "refresh_token": "rft_example_only"
}
Responses
200New token pair; old refresh token invalid
400Malformed or missing request fields
401Invalid, expired, revoked, or reused token
429Too many refresh attempts
GET

/posts/{id}

Read a private post belonging to the caller. Other users' posts return 404.

Required scope
posts:read Bearer JWT
Path and response
id: UUID
200: { id, author_id, content,
       created_at }
Responses
200Caller owns the post
400Invalid post ID
401Missing, invalid, or expired JWT
403Missing posts:read scope
404Post absent or not owned by caller
